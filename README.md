# Proyecto Web - Grupo 33

Proyecto listo para subir a GitHub.

## Archivos
- `index.html`: página principal.
- `perfil.html`: perfil de Gabriel.
- `bitacora.html`: bitácora del proyecto.
- `css/estilos.css`: estilos generales y responsive.
- `js/script.js`: función dinámica.
- `img/`: carpeta para imágenes.

## Subir a GitHub
Crear un repositorio nuevo y subir el contenido de esta carpeta manteniendo la estructura.
`index.html` debe quedar en la raíz del repositorio.
