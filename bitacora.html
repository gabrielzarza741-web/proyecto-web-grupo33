Etapa 1 - Organización

Decisión: Organizamos las tareas y definimos la estructura del sitio.

Dificultad: Distribuir correctamente las páginas y archivos.

Solución: Creamos una estructura común para todo el equipo.

Etapa 2 - Diseño

Decisión: Utilizamos una misma paleta de colores y la fuente Poppins.

Dificultad: Mantener el mismo diseño en todas las páginas.

Solución: Centralizamos los estilos en un único archivo CSS.

Etapa 3 - Navegación

Decisión: Incorporamos enlaces para Inicio, Integrantes, Perfil y Bitácora.

Cambio: Agregamos botones internos para no depender del botón Atrás del navegador.

Etapa 4 - JavaScript y publicación

Decisión: Incorporamos una función dinámica en el perfil.

Objetivo: Preparar el proyecto para publicarlo en GitHub y luego en Vercel.
